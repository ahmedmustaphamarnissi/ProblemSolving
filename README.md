## 📚 Topics Covered (Course 23 Deep Dive)

### 1. Basic Searching Algorithms

Searching is the foundation of all algorithm design. This section covers the two fundamental search strategies and their complexity trade-offs.

| Algorithm | Time Complexity | Description |
|---|---|---|
| Linear Search | O(n) | Scans every element until found |
| Binary Search | O(log n) | Divides sorted array in half each step |

**Example problems:**
- Implementing Linear Search in C#
- Implementing Binary Search iteratively and recursively
- Analyzing when to use each search strategy

---

### 2. Simple Sorts

Understanding sorting algorithms from first principles — not just memorizing them, but understanding why their complexity is what it is and when each is appropriate.

| Algorithm | Time Complexity | Space | Stable |
|---|---|---|---|
| Bubble Sort | O(n²) | O(1) | ✅ Yes |
| Selection Sort | O(n²) | O(1) | ❌ No |
| Insertion Sort | O(n²) best O(n) | O(1) | ✅ Yes |

**Example problems:**
- Implementing all three sorts from scratch in C#
- Comparing performance on sorted vs. unsorted input
- Choosing the right sort for small datasets

---

### 3. Tree Traversal Algorithms

Tree traversal defines how you visit every node — the order matters enormously depending on the problem.

| Traversal | Order | Use Case |
|---|---|---|
| Pre-order | Root → Left → Right | Copy a tree, prefix expressions |
| In-order | Left → Root → Right | Sorted output from BST |
| Post-order | Left → Right → Root | Delete a tree, postfix expressions |
| Level-order (BFS) | Level by level | Shortest path in unweighted trees |

**Example problems:**
- Implementing Level-order Traversal (BFS) in C#
- Pre/In/Post-order traversal of a binary tree
- Maximum Depth of a Binary Tree
- Print the largest value at each level of a binary tree

### 5. Balanced Trees — AVL Tree

An AVL tree solves the BST worst-case problem through self-balancing rotations. Every insertion or deletion guarantees O(log n) height.

**Rotations covered:**
- RR — Single Right Rotation
- LL — Single Left Rotation
- LR — Left-Right Double Rotation
- RL — Right-Left Double Rotation

**Operations covered:**
- Insertion with automatic rebalancing
- Deletion with violation fixing
- Search in O(log n) guaranteed

**Example problems:**
- Full AVL Tree implementation in C#
- Deletion in AVL Tree with all rotation cases
- Real-life application: **Autocomplete feature** using AVL Tree

---

### 6. Balanced Trees — Red-Black Tree

Red-Black Trees offer slightly looser balance guarantees than AVL trees but achieve faster insertions and deletions — making them the preferred choice in most standard library implementations (C++ `std::map`, Java `TreeMap`).

**Properties enforced:**
- Every node is Red or Black
- Root is always Black
- No two consecutive Red nodes
- All paths from root to null have equal Black-height

**Operations covered:**
- Insert with color rebalancing
- Search operation
- Delete with violation fixing across all sub-cases (DB cases, sibling color cases)

**Example problems:**
- Implementing Insertion in C# with full rotation and recoloring
- Implementing Delete with all violation fix cases
- Comparison: AVL Tree vs Red-Black Tree — when to use which

### 7. Graph Traversals — BFS & DFS

Graphs are the most general data structure — understanding how to traverse them is essential to solving problems in networking, AI, pathfinding, and system design.

| Algorithm | Structure Used | Explores |
|---|---|---|
| BFS (Breadth-First Search) | Queue | Level by level, finds shortest path |
| DFS (Depth-First Search) | Stack / Recursion | Deep first, useful for cycle detection |

**Example problems:**
- BFS Implementation in C#
- DFS Implementation in C#
- Difference between BFS and DFS — when to use each
- Representing a Social Network (graph problem)

---

### 8. Shortest Path Algorithms — Dijkstra

Dijkstra's algorithm finds the shortest path from a single source to all other nodes in a graph with non-negative weights — one of the most important algorithms in computer science.

**Implementations covered:**

| Approach | Complexity | When to use |
|---|---|---|
| Adjacency Matrix | O(V²) | Dense graphs |
| Adjacency List + Min-Heap | O((V+E) log V) | Sparse graphs (optimized) |

**Example problems:**
- Dijkstra Algorithm implementation step by step
- **Shortest Time to Travel Problem** — real-world route optimization
- Optimizing with Priority Queue (Min-Heap)

### 9. Greedy Algorithms

Greedy algorithms build solutions incrementally by always making the locally optimal choice. They are fast, elegant, and powerful — when the problem has the greedy choice property.

**Example problems:**
